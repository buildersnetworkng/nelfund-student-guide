# NELFUND Student Guide

An independent, unofficial guide to the Nigerian Education Loan Fund (NELFUND) for Nigerian tertiary students.

- Nationwide NELFUND information at the core
- Institution-aware architecture (OOU developed; others supported as stubs)
- Trust labels on every fact (Verified / May Change / General Guidance / Unverified)
- Search, troubleshooting, readiness checklist, step-by-step application guide, videos, official sources

**Not produced or endorsed by NELFUND or any institution.** Always confirm important decisions on the official portal: https://nelf.gov.ng/ and https://portal.nelf.gov.ng/

## Stack

Vite + React 18 + TypeScript + Tailwind CSS + react-router-dom

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Deployed on Vercel with SPA rewrites (`vercel.json`).
